## Вариант 4
Выполнил студент гр. №4941104/40701, А.А. Губин    
### Задание    
Согласно варианту 4 требовалось настроить ядро таким образом, чтобы при проверке исключения Breakpoint sbreak.S выводилась     строка «break». При этом, Reset Vector и Trap Vector имеют значения 0x800 и 0x6с0,     соответственно.    
### Реализация    
Для достижения поставленной задачи были отредактирован список тестов (/scr1/sim/tests/riscv_isa/rv32_tests.inc) так, что на выполнение остался только тест по варианту задания (sbreak.S). Далее была модифицирована обработка исключений в файле riscv_macros.h. Были установлены параметры ядра Reset Vector (SCR1_ARCH_RST_VECTOR) и Trap Vector (SCR1_ARCH_MTVEC_BASE) на 0x800 и 0x6с0. Для успешной сборки был изменен linker-скрипт (sim/tests/common/link.ld).
